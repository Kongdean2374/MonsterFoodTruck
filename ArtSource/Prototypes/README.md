# 單角色分層試稿

`dragon-layer-rig.png` 是以已保存的三角色母版中的焰尾龍作參考，使用本次可用 OpenAI image generation／參考圖編修工具生成的單角色試稿。原始母版未覆蓋。2026-10-20 生成八部件試稿後，參考同一張圖移除軀幹前臂，供獨立手臂接合。保留完整未修改的生成 PNG（887×1774 RGBA）。

五種頭部：待機、期待、低耐心、滿意、離開／失望；另外軀幹、手臂、尾焰。JSON 是對原始 Alpha 的部件位置分析，僅供 App 執行時 subtexture 裁切，不以腳本重畫或合成成品圖。

此稿不是實際 App 截圖，也尚未通過 Dot 視覺門檻。僅 DEBUG 的 `MFT_DRAGON_RIG=1` 預覽採用分層 SpriteKit 試裝；Release 沿用現有母版，等待真實小尺寸接合檢視後再決定後續製作。沒有將試稿擴稱三角色動畫完成。

來源與權利依據沿用 [資產清單](../../docs/ASSET_MANIFEST.md) 的本專案原創生成紀錄及 OpenAI 使用條款；未新增外部素材或指定再利用授權。

`kitchen-layers.png` 是參考同一餐車森林與料理母版生成的初始工作區六部件樣本（1536×1024 RGBA）：森林、車體、木檯、單爐、成品墊與備料板。JSON 僅記錄原始 Alpha 的部件位置。僅 DEBUG 的 `MFT_KITCHEN_LAYERS=1` 試裝車體、森林、檯面及工位；搭配龍試稿取得真實一般／大字左手畫面，尚未宣稱實際畫面或 Dot 通過。爐具樣本含固定火焰，正式版仍須分離熄火與點火狀態。原 PNG 不修改，Release 沿用原介面。
