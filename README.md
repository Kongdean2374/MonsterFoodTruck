# 魔物餐車 · MonsterFoodTruck

原生 iPhone 直式、完整離線的單人雙爐料理遊戲開發專案。目標包含三種魔物、三道料理、六個關卡，以及首頁、教學、選關、設定、存檔恢復與正式美術音訊。

目前已完成 **P0 倉庫與讀寫權限驗證**，已實際 clone、push 並從 GitHub 讀回規格比對。本階段只建立開發依據與工作紀錄，尚無可遊玩的遊戲、已驗證工程、正式素材、成功建置或 IPA。
