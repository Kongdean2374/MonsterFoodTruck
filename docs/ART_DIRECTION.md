# 黃昏森林餐車

母版為 `ArtSource/Masters/characters-and-dishes.png`、`forest-food-truck.png` 與 `app-icon.png`。風格固定為暖色童話 gouache、柔和深可可輪廓、少量紙感、上左暖光；不用現成 IP 或指定藝術家風格。

三角色依序：橘紅奶油肚的焰尾龍、紫色長耳饞嘴小鬼、奶油棕與苔綠小角的苔角鹿。三菜依序：陶碗星火濃湯、木盤月角脆餅、深綠盤雲菇燉菜。角色 atlas 上排採 y=0..540，下排料理 y=540..1024，各列寬 512；遊戲用 runtime subtexture，不反覆自由重畫。

UI 以真實系統文字與可操作按鈕疊在圖像上，生成圖沒有 UI 字樣。奶油 `#FFF3D6`、可可 `#3B2B2A`、苔綠 `#657B51`、暖橘 `#E98A49`、紫 `#8061A3`、青藍 `#467F86` 為起點；警告仍需符號、文字與數字。餐蓋為程式繪製的有陰影金屬罩，素材來源可維護。

已檢視母版大圖與 alpha 數值：1536×1024 RGBA，有透明區域。這不取代實際 App 的縮小、深淺底、裁切、動畫與忙碌場景檢查。三尺寸、大字與高對比證據尚待產生。現有角色只完成母版與初步動態，尚缺規格要求的分層表情／動作，不將整張圖擺動視為全部動畫完成，也尚未取得 Dot 美術量表判定。

Icon 為以兩張母版作參考的原創生成圖，原檔 1254×1254 RGB；macOS `sips` 只作 1024×1024 尺寸正規化供 asset catalog，保留原圖，不改角色與構圖。這是可重現的資產編譯前處理。
