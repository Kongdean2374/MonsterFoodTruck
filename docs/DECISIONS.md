# 實作決策

- 工程不引入第三方相依；Python 標準庫產生並提交 Xcode project／scheme，CI 重生後比對。
- `.app` 根目錄不放 `Resources`／`Contents` 保留目錄。DOT-001 已由 native Foundation 重現布局差異並由 Dot 查驗實際裝置 IPA；所有普通資源使用標準逐檔複製。來源目錄仍按職責組織，檔名需全域唯一。
- 遊戲時間由純 GameSession 控制，UI／重播走相同命令驗證；SpriteKit 動畫不決定分數或工序真相。長畫格按到期事件切分，不截短 elapsed time。
- 初版數值與六關腳本沿用規格起始假設。b88566e 的模型測試已實際完成普通／舒緩六關三星參考解與重播；這只證明模型可解，尚未證明正常玩家的策略樂趣與餐蓋價值，後兩關節奏仍須用實際畫面／策略比較診斷。
- 存檔採單一原子文件，包含永久進度、設定及 session，結算寫入星數與清除 session 在同一份文件中。序列寫入拒絕舊 revision；備份只由有效前一版更新。
- 教學重看使用 practice 標記，走真實命令但不更新正式紀錄／解鎖。正式教學仍可推進第一局，略過不產生假分數。
- 音訊使用專案原創音符與合成音色，離線 WAV 隨包，無外部音訊樣本或執行期生成。靜音與中斷遵循 ambient audio session；警告有優先發聲路徑，最多六個短音效同時播放。
- 起鍋安全寬限最後兩秒，Domain 發出一次 scorchWarning，沿用原創過熟提示音並顯示「快起鍋」；不改食譜時間／寬限、熱度或評分。長畫格仍按事件時間排序，測試確認預告先於過熟兩秒。
- 違規操作以不中斷操作的行內文字提示；需確認的存檔錯誤會暫停遊戲。設定的「完成」等待最新寫入，還原／清除確認在設定關閉後才呈現，避免兩張 sheet 交錯。
- Validate 的主測試與小／大尺寸分成同 SHA 獨立 job，fail-fast 關閉、不自動取消已執行 run；原失敗仍在主測試完整執行，尺寸各自保留原生結果與 PNG，不以其中一筆成功代表整體通過。
